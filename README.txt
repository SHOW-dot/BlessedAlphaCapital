BLESSED ALPHA CAPITAL WEBSITE

FILES
- index.html
- style.css
- script.js
- assets/logo-bac.png

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Replace assets/logo-bac.png with your own transparent PNG logo.
4. Keep the same filename, or update the image src paths in index.html.

HOLDING STRUCTURE ANIMATION
- PT. A is positioned at the upper-left.
- PT. B is positioned at the upper-right.
- PT. C is positioned at the lower-center.
- Light moves from the BAC logo toward each company.
- The light stops at the edge of each box.
- An SVG light then follows the rounded border exactly once.

IMPORTANT
Each company node appears only once in the HTML. Do not duplicate:
- company-node node-a
- company-node node-b
- company-node node-c
